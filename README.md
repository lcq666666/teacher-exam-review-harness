# 教师讲评助手 · 红笔版（redpen 分支）

与 main 的分册手册版是同一个工具的两个样子：功能、诊断数字、操作步骤完全一样，只换视觉世界。

- 纸白底、墨字、宋体标题，红笔红（#b3271e）只做批改用：做完的步红框加红勾，当前步红框加粗，重点讲标题下红波浪线，重点讲徽章红底白字，偏弱分段红色。
- 步骤条横向一排纸卡。
