# 教师讲评助手 · v1

老师一次考试的讲评准备工具：上传成绩表（宽表 Excel/CSV），试卷处理（OCR 或直接上传题目与知识点对应表），跑统计、ESCT 诊断、生成讲评提纲，每步停下来等老师确认。

在线打开：https://lcq666666.github.io/teacher-exam-review-harness/

也可以把 `index.html` 下载下来，双击用浏览器打开，离线也能用（第一次用 OCR 要联网加载 PaddleOCR 和模型，之后缓存），数据只存在自己电脑里。

## 怎么用

1. 打开页面，上传成绩表（Excel 或 CSV），或点“加载演示数据”先试一遍。
2. 看统计：平均分、每题得分率、分数分布。
3. 看诊断：全班卡在哪个知识点，哪些是有证据的、哪些是推断的。
4. 改讲评提纲：顺序能调，条目能删，改完导出。

## 文件说明

- `index.html`：工具本身。宽表成绩表上传与校验、试卷处理、统计、诊断、讲评提纲，五步带确认关卡。试卷 OCR 用 PaddleOCR（第一次用时从网上加载，之后缓存），打不开时自动换 Tesseract.js。
- `samples/模拟成绩表.csv`：模拟的成绩表，30 名学生 × 10 道题，宽表格式。
- `samples/模拟试卷知识点对应表.csv`：题目和知识点的对应关系。
- `samples/模拟成绩表-长表导入版.csv`：同一份成绩的长表版，也能导进工具跑。

需求文档和执行方案在需求文档里，见仓库外的项目记录。学生姓名和分数全是模拟的，没有真实学生信息。
